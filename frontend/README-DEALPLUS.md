# DealPlus frontend

This folder contains the original uploaded DealPlus React/Vite demo, preserved as supplied, plus empty target feature folders under `src/modules/`.

Run:
```bash
npm install
npm run dev
```

The demo is currently JSX/JavaScript, not TypeScript. The new feature folders are scaffolding only. Refactor existing screens incrementally and connect them to the API Gateway once API contracts are agreed.
